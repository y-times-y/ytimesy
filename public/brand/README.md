# ytimesy logo

Approved faceted Y mark. All SVGs have transparent backgrounds and a 32 × 32 viewBox.

Names describe the artwork color, not the interface theme:

- `mark-dark.svg`: dark charcoal artwork for light backgrounds.
- `mark-light.svg`: light white and gray artwork for dark backgrounds.
- `mark.svg`: the current website asset, identical to `mark-light.svg`.

Preserve the geometry, aspect ratio, and flat facets. The taller right arm is intentional.
